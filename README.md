## 1. 这是什么

`index.html` 是一个自包含的网页应用，用来回答一个问题：

> **在《心跳回忆》里，从某个存档点出发，每周该下什么指令，才能在毕业时把九项属性尽量推到目标值？**

它做的事：

- 按你填写的**当前属性**和**目标属性**，在「当前日期 → 毕业日 1998-03-01」的完整区间上搜索最优排程；
- 你可以自由标注日历：某天设为休日、某天跳过、某周强制某个指令；
- 求解结果给出**逐周 / 逐休日的指令表**、**达标核对表**和**逐日属性轨迹**；
- 你在月历上改动标注时，只重排**改动点之后**的安排，之前的排程保持不动（见 [§5.8](#58-增量重规划只改动编辑点之后的排程)）；
- 全程在浏览器本地完成，**不发起任何网络请求，不上传任何数据**。

| 特点 | 含义 |
| --- | --- |
| 单文件 | 全部 HTML / CSS / JS 内联在 `index.html` 里，拷走一个文件就能用 |
| 零依赖 | 不依赖框架、CDN、字体或任何外部资源，断网也能跑 |
| 免安装 | 不需要安装任何运行环境，双击打开即可 |

## 2. 快速开始

### 2.1 打开

直接用浏览器打开 `index.html`（图形界面里双击，或用命令行 `xdg-open index.html` / `open index.html` / `start index.html`）。

首次打开会**自动求解一次**（用的是默认输入），所以你立刻就能看到一份示例排程。

### 2.2 最小操作流程

1. **输入面板**：填写「当前日期」、当前属性值、目标值；需要的话选一个社团。
2. **月历标注**（可选）：把你已知的固定安排点进去 —— 例如「这几周必须休息」「这几天跳过」。
3. 点 **求解**（改动输入后也会自动求解），在**结果面板**查看结论与排程。
4. 用结果面板的三个页签核对：`排程指令` / `达标核对` / `属性轨迹`。

### 2.3 浏览器要求与存档提示

需要支持 ES2017+、CSS Grid 与 `input[type=date]` 的现代浏览器：Chrome / Edge 88+、Firefox 90+、Safari 14.1+。

> **关于 `file://` 与存档**：直接双击打开（`file://` 协议）时，部分浏览器会禁用或隔离网页存储。本工具对此做了兜底：一旦写入失败会自动退化为**内存存储**，功能不受影响，但**刷新页面后输入与标注会丢失**。想稳定保存，可以用任意静态服务器打开，例如：
> ```bash
> python3 -m http.server 8000    # 然后访问 http://127.0.0.1:8000/index.html
> ```

## 4. 输入面板

| 控件 | 说明 |
| --- | --- |
| **当前日期** | 计划的起点（存档点）。可选范围 **1995-04-01 ~ 1998-03-01**，默认 `1995-04-04`（游戏开局）。被夹在范围外的旧存档会自动夹回边界。 |
| **社团** | `不参加社团` 或 11 个社团之一。选了社团后，「社团活动」才出现在指令下拉框里，并启用[社团分配约束](#76-社团分配要求)。 |
| **当前值** | 九项属性在**当前日期**的值，必须是 `0 ~ 999` 的整数。 |
| **目标值** | 你希望**毕业时**达到的值。注意方向：前八项是「**≥ 目标**」，压力是「**≤ 目标**」（所以 `压力` 标着「（≤）」，其余标着「（≥）」）。 |
| **求解** | 立即求解（正常情况下改动输入后约 0.3 秒会自动求解，这个按钮用于手动重算）。 |
| **恢复默认** | 把日期、社团、九项当前值 / 目标值全部还原为默认；**日历上已有的标注会保留**（整周的强制指令会被清除）。 |

默认输入：

| 属性 | 体力 | 文科 | 理科 | 艺术 | 运动 | 人缘 | 容貌 | 智力 | 压力 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 当前值 | 100 | 40 | 40 | 40 | 40 | 32 | 60 | 5 | 0 |
| 目标值 | 60 | 80 | 80 | 80 | 60 | 60 | 80 | 60 | 50 |

> 数值输入框只接受 `0 ~ 999` 的整数。填错时输入框会变红，**该次改动不会被采用**（保留上一个合法值）。

## 5. 月历标注

月历是你和求解器沟通的主要方式：**你没标的日子，求解器自由决定；你标了的日子，必须照办。**

### 5.1 视图与导航

- 一次显示**两个自然月**（起始月 + 下一月）。
- 每行是一个自然周，**行首格**给出该周的描述与整周指令下拉框：
  - `第 N 周`：从求解起点算起的周序号；
  - `6/05~6/10`：该周平时块的月份 / 日期区间；
  - `6 天`：该周**平时日**的天数（周日恒为休日，不参与计数）；
  - 下拉框（标题「整周指令」）：给这一周的**全部平时日**指定同一个指令，默认「自动」。
- `‹` / `›` 翻月，`回到当前月` 跳回当前日期所在月。翻月**不会重新求解**，只是换一个两月切片查看结果。
- 求解区间外的日期显示为灰色虚线格，不可点击。

### 5.2 单元格的形态

| 外观 | 含义 |
| --- | --- |
| 蓝色格 | **平时日**（周一至周六）。同一周的所有平时日共享一条指令。 |
| 黄色格 | **休日**：周日自动成为休日，也可以把任意平时日手动设为休日。休日有自己独立的指令。 |
| 灰色删除线格 | **跳过**：这一天完全不参与计算（不产生决策、不改变属性、不参与路径检查）。 |
| 格子右上角 `〔休〕` `〔跳〕` `🔒` | 分别是「手动休日」「跳过」「强制指令」标记。 |
| 格子左下角 `⚠体` `⚠压` | 该天结算后违反路径约束（体力 < 20 / 压力 > 70）。 |

### 5.3 单日操作：点击格子

**单击**任意格子弹出菜单，可选项随格子状态变化：

- 平时日 → `设为休日`、`强制指令`（下拉选择）；
- 手动休日 → `取消休日`、`跳过这一天`、`强制指令`；
- 已跳过的日子 → `恢复`；
- 周日 → 只有 `跳过这一天` 和 `强制指令`（周日**永远**是休日，不能取消）。

### 5.4 批量操作：拖拽框选

在日历上**按住鼠标拖过一段日期**，松开后出现批量操作条：

| 按钮 | 效果 |
| --- | --- |
| `全部设为休日` | 区间内所有平时日变成休日（周日本来就是休日，不受影响）。 |
| `全部跳过` | 区间内所有日子跳过（平时日会先变成休日再跳过 —— 跳过只能从休日进入）。 |
| `清除标记` | 清除区间内的休日 / 跳过 / 强制标记（周日的休日属性固定，只清除跳过与强制）。 |
| `取消选择` | 收起操作条，不做改动。 |

### 5.5 两条必须记住的规则

1. **周日永远是休日**，不能被取消。想「不做任何事」只能选择**跳过**。
2. **跳过只能从休日进入**：对平时日直接按跳过是无效的（会先自动设为休日）。

### 5.6 ⚠ 一个容易踩的坑：平时日的「强制指令」

「强制指令」有两种入口，作用范围不同：

| 入口 | 作用范围 | 是否影响求解 |
| --- | --- | --- |
| 行首下拉框（「整周指令」） | 该周**全部平时日** | ✅ 会影响 |
| 单元格菜单里的「强制指令」 | 该**单日** | ⚠️ **只有休日（含周日）生效** |

也就是说：**在平时日格子上通过菜单设置的强制指令不会约束求解器**，格子上虽然会显示 `🔒`，但求解结果可能仍是别的指令。
给平时块指定指令，请一律使用**行首的整周下拉框**；单元格菜单里的强制指令用于锁定**某个休日**的安排。

### 5.7 社团活动的可用时间

「社团活动」最早只能在 **1995-04-09**（开局后的第一个周日）加入。在此之前，周下拉框和单元格菜单里都不会提供该指令。

### 5.8 增量重规划：只改动编辑点之后的排程

在月历上做标注（设休日 / 跳过 / 整周指令 / 单元格强制指令）时，工具**不会重排整段历史**：

- 只允许改动你编辑的**那一天及之后**的规划；
- 该日期**之前**已经算好的排程原样保留，这些行在「排程指令」里标为 `🔒 已固定`；
- 修改输入面板（当前日期 / 社团 / 属性 / 目标）或点「恢复默认」会放弃固定，回到整段全局重算。

固定的范围按编辑动作确定：

| 编辑动作 | 固定「该边界之前」的范围 |
| --- | --- |
| 把某天设为休日 / 取消休日 | 该天之前的所有周与休日 |
| 强制某一周（行首下拉框） | 该周之前的所有周与休日 |
| 跳过 / 恢复某个休日 | 该天之前的所有周与休日 |
| 拖拽批量操作 | 选中区间**起点**之前的所有周与休日 |

- 被编辑那一天**所在的周**允许重排 —— 改休日 / 跳过会改变这一周的平时块天数，强行固定反而与你的操作冲突。
- 连续改动时以**最早**的那个日期为准；`求解` 按钮、以及改动后的自动求解，都会继续沿用同一批固定项。
- 固定信息随存档保存（见 [§9.1](#91-自动保存)），刷新页面后仍然延续同一份历史。
- 想放弃增量、回到「整段重新求最优」，点「排程指令」页里的 **解除固定，全局重算**。

## 6. 结果面板

结果面板 = **一条结论 + 一行元信息 + 三个页签**。

### 6.1 结论条

按求解状态显示四种颜色 / 文案（详见 [§8](#8-四种求解状态)）。只有在**没有解**时，才会额外出现一个归因框说明原因。

### 6.2 元信息行

```
全局求解 1995-04-04 ~ 1998-03-01（毕业） · 显示 1995-04-04 ~ 1995-05-31（两月） · 总差距 12.5 · 3 ms
```

- **全局求解区间**：始终是「当前日期 → 毕业日 1998-03-01」。排程是按整段算出来的，不会因为翻月而改变。
- **显示区间**：当前月历所在的两个月，只影响下面表格**展示**哪些行。
- **总差距**：毕业时九项未达标缺口之和（见 [§7.3](#73-目标函数总差距)）。
- **用时**：本次求解耗时。

> 「求解」按钮旁也会同步显示 `用时 X ms · 状态 <status>`。

### 6.3 页签一：排程指令

按时间排序合并了**逐周指令**与**逐休日指令**：

| 列 | 含义 |
| --- | --- |
| 日期 | 平时块显示 `MM-DD~MM-DD` 区间，休日显示单个日期。 |
| 类型 | `第 N 周 · 平时块 M 天` / `休日 · 周日` / `休日` / `跳过`。 |
| 指令 | 该周或该休日安排的具体指令。 |
| 备注 | `🔒 强制` 表示该条是你自己锁定的；`🔒 已固定` 表示该条属于增量重规划保留的历史（见 [§5.8](#58-增量重规划只改动编辑点之后的排程)）。 |

选了社团时，表格上方还有一行**社团分配**进度：

- 生效时：`社团分配（全程累计）：游泳社 · 354 / 需 350 天 · 截止 1998-01-03`（不达标会标红）；
- 当前日期不是开局 `1995-04-04` 时：提示「仅从开局 1995-04-04 开始求解时检查」；
- 截止日已过时：提示「已过，本次计划不再检查」。

### 6.4 页签二：达标核对

九项属性在**毕业终点**的值、目标、差值与结果：

| 列 | 含义 |
| --- | --- |
| 终点值 | 毕业时的属性值（不是当前显示月度的值）。 |
| 目标 | 你填的目标值。 |
| 差 | 达标余量：前八项为 `终点值 − 目标`（正数=超出），压力为 `目标 − 终点值`。 |
| 结果 | `✓` 达标；`✗` 未达标；`✗ 不可达` 表示**结构性不可达** —— 即使全程乐观估计也到不了目标，与排程无关（常见于当前日期已经很晚、剩余时间不够，或目标本身定得太高）。 |

不达标的行整行标红。若存在不可达项，表下会给出「全局乐观上界 ≤ 可达值 < 目标」的说明。

### 6.5 页签三：属性轨迹

显示区间内**逐日**的九项属性值（每行一天，最多约 62 行，可滚动）。违反路径约束的行整行标红。跳过日不产生影响，因此不会违反约束。

## 7. 计算口径

这一节说明工具判断「什么方案合法、什么方案最优」的依据，方便你理解结果。

### 7.1 时间与决策点的划分

| 概念 | 规则 |
| --- | --- |
| 求解区间 | `当前日期 → 1998-03-01`（毕业日），默认起点 `1995-04-04`。 |
| 一周 | 以**周一**为界，周的划分不受月份影响（跨月周照样算一周）。 |
| 平时块 | 一周内的**周日以外**的日子（周一至周六），共用一个指令；若其中有几天被设为休日或跳过，这一周的实际天数会变少。 |
| 休日槽 | 每个周日 + 你手动标记的休日，每个都有自己独立的指令。 |
| 跳过 | 不产生决策点，不改变任何属性。 |
| 没有平时日的周 | 不产生决策点（即使设了整周指令也会被忽略并提示）。 |

### 7.2 指令与属性变化

可用指令共 **8 类**：7 条基础指令 + 1 条「社团活动」。未选社团时「社团活动」不可用，此时实际只有 7 类。

每次结算的属性变化量：

| 场景 | 天当量 | 基础指令变化量 | 社团活动变化量 |
| --- | ---: | --- | --- |
| 平时日的每一天 | 1 | `T / 30` | `T / 36` |
| 一个休日槽 | 4 | `(4 / 30) × T` | — |
| 一个休日槽选「社团活动」 | 6 | — | `(6 / 36) × T` |

其中 `T` 是[附录 A](#附录-a基础指令效果表) / [B](#附录-b社团一览) 表中的数值，含义是「连续三周都选同一指令」的属性总变动。

**休日是一次性结算**：4（或 6）天当量一次算完，只在结算后检查一次路径约束，中途不检查。

### 7.3 目标函数（总差距）

只有**毕业终点**参与达标判定，与当前翻到哪个月无关。

```
总差距 = Σ(前八项) max(0, 目标ᵢ − 终点值ᵢ)  +  max(0, 压力终点值 − 压力目标)
```

求解器的目标就是让这个值越小越好；`总差距 = 0` 即「全部达标」。

### 7.4 取值范围与路径约束

| 规则 | 说明 |
| --- | --- |
| 属性饱和 | 任何时刻属性被夹在 **0 ~ 999**。到顶 / 到底后再吃对应指令不会继续溢出。 |
| 路径约束（硬） | 每个**决策日结算之后**必须满足 **体力 ≥ 20** 且 **压力 ≤ 70**。违反意味着这份排程不可执行，求解器会绕开它。 |

### 7.5 强制与互斥

- 整周指令与休日强制指令都是**硬约束**：求解器必须在满足它们的前提下找最优解。
- **强制与跳过互斥**：被跳过的日子没有决策，强制标记会被忽略。
- 若你设置的强制组合本身不可行（例如全程强制「研究文科」导致体力跌破 20），会得到 `无法求解` 并指出冲突点。

### 7.6 社团分配要求

选定社团后，游戏要求你在截止日前攒够「社团分配天数」：

| 类别 | 门槛 | 截止日 |
| --- | ---: | --- |

## 8. 四种求解状态

| 状态 | 结论条 | 含义 | 你要做什么 |
| --- | --- | --- | --- |
| `ok` | 🟢 **全部达标** | 找到方案，毕业时九项全部满足目标。 | 直接照「排程指令」执行。 |
| `targets_missed` | 🔴 **未达标：总差距 X（明细…）** | 已找到**最优**排程，但目标组合本身无法全部达成。 | 看「达标核对」的差值，酌情下调目标或改用别的社团。 |
| `undetermined` | 🟠 **未确定：搜索预算耗尽…（近似结果）** | 搜索达到预算上限，给出的是**近似最优**方案，并附「已认证最优性间隙 ≤ X」。 | 结果是可用的好方案，但可能不是绝对最优；可放宽目标后重试。 |
| `path_infeasible` | 🔴 **无法求解：<原因>** | 在满足你的强制标注 / 社团要求的前提下，找不到任何满足路径约束的排程。 | 按提示的「第 N 周…越界」或冲突表调整标注；该解只用于诊断定位，不作为可执行方案。 |

> 目标定得极其激进（例如九项全填 999）时出现 `未确定` 是正常现象 —— 这类实例的最优性很难证明，工具选择「给你一个好方案 + 坦诚说明不是最优」，而不是假装结论确定。

## 9. 存档、恢复默认与数据清理

### 9.1 自动保存

输入变化和日历标注变化后会**自动写入浏览器存储**，所以关闭或刷新页面后内容还在：

- 当前日期、社团、九项当前值 / 目标值、整周强制指令；
- 逐日标注（休日 / 跳过 / 强制），**按绝对日期保存**；
- 主题、当前显示的月份、结果页签，以及增量重规划的固定前缀（见 [§5.8](#58-增量重规划只改动编辑点之后的排程)）。

因为标注按绝对日期存放，**翻月、改当前日期都不会让标注错位**。

### 9.2 清空存档

浏览器开发者工具 → `Application` / `存储` → `Local Storage` → 删除 `temeo.v1.*` 开头的键，然后刷新页面。
（也可以在浏览器设置里「清除该站点的数据」。）

### 9.3 恢复默认的边界

- `恢复默认` 按钮：重置输入面板内容，**保留日历上的逐日标注**，但会**清空整周强制指令**。
- 想连标注一起清掉：用 [§5.4](#54-批量操作拖拽框选) 的 `清除标记` 批量清除，或按 §9.2 清空存档。

## 10. 常见问题（FAQ）

**Q1. 打开后一直显示「未确定」怎么办？**
目标过高时最优性难以证明。可以先只保留最关心的几项目标，把其余目标调低，再逐步提高，观察总差距的变化。

**Q2. 为什么我标的「强制指令」没有生效？**
多半是标在了**平时日**格子上 —— 平时块请用行首的**整周下拉框**设置（见 [§5.6](#56--一个容易踩的坑平时日的强制指令)）。

**Q3. 为什么「达标核对」里的终点值和我翻到的那个月对不上？**
达标判定一律以**毕业终点**为准，与当前显示的两个月无关；想看逐日变化请用「属性轨迹」页签。

**Q4. 压力怎么填？**
压力是**上限**：填 50 表示要求毕业时压力 ≤ 50，而不是 ≥ 50。其余八项是**下限**。

**Q5. 体力 / 压力经常冒警告怎么办？**
`⚠体` / `⚠压` 表示当天结算后违反了 体力 ≥ 20 / 压力 ≤ 70。把这些日子设为休日或改为「休息」，通常能缓解；如果整周都是强制指令，可能需要放宽强制。

**Q6. 刷新后我的标注没了？**
确认是不是用 `file://` 直接打开的 —— 部分浏览器在该协议下禁用网页存储，本工具会退回内存存储。用本地静态服务器打开即可稳定保存（见 [§2.3](#23-浏览器要求与存档提示)）。

**Q7. 我只改了一天，为什么后面的排程全变了？**
这是正常的：改动点**之前**的排程已固定不变，改动点**之后**的排程会重新优化，所以看起来「后面全变了」。这些被固定的行会标为 `🔒 已固定`。想彻底重排整段，点「排程指令」页里的 **解除固定，全局重算**（详见 [§5.8](#58-增量重规划只改动编辑点之后的排程)）。

**Q8. 结果可靠吗？**
排程满足全部硬约束（路径约束、强制标注、社团分配），并且经过精确模拟复核。区别只在于最优性：`ok` / `未达标` 是**已证明最优**的解；`未确定` 是带最优性间隙的**近似最优**解。

**Q9. 能改数值 / 用到别的游戏吗？**
本工具的数值固定为《心跳回忆》原作数据，不提供界面修改。
